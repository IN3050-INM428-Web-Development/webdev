# Images

All images in this folder come from the Al Sah-him Archery Club information
package supplied for IN3050 Coursework 1. The logo is the club's own logo and
the photographs are licensed stock images from that package.

The `-800` and `-1600` files are responsive copies of the same photograph,
resized from the originals so the site can serve a sensible file size on phones
and larger screens. The `-square-` files are cropped for the mobile hero image.
