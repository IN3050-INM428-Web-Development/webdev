# Coursework 1 — Starter Template

This repository is your starting point for Coursework 1. Please keep the
folder and file layout below exactly as it is as the required submission
structure depends on it, and work that doesn't match it exactly loses marks
(see the coursework brief).

## Structure

```
website/
  index.html          your HTML goes here
  styles.css          write your CSS here
  assets/
    images/             put any images you use here
```

## Workflow

1. Edit `website/index.html` and `website/styles.css` directly. This
   coursework uses plain CSS.
2. Commit and push your changes as you build out your site. Commit and
   push often: building your site up gradually, rather than all at once
   right before the deadline, matters for your mark (see the coursework
   brief for details).

## Submitting

Push your work to GitHub regularly as you go as your repository **is**
your submission, there's no separate zip file to upload anywhere.

Your most recent commit on `main` before the deadline is what gets graded
automatically. If you want to mark a specific commit as your definitive
final version (for example, if you keep tinkering after you think you're
done), make one commit with the exact message `Final submission` and that
commit will be used.

You still need to separately submit your video and statement on Moodle. 
See the "GitHub Classroom 50, Student Submission Guide" there for full
details. Your mark for this coursework only counts if both the Moodle
submission and your GitHub repository are complete.
